# ここにRVCモデルを置きます（Gitには入りません）

```
models/
  好きなモデル名/
    xxxx.pth        ← RVCの重み
    xxxx.index      ← 任意（あると声質が安定）
```

- このフォルダの中身は `.gitignore` で除外されています。**コミット・公開しないでください。**
- Hugging Face の `NoCrypt/miku_RVC` はライセンス記載がなく、モデルカードも配布元(Google Drive)へのリンクのみです。
  再配布が許可されているか確認できないため、このリポジトリには含めていません。ご自身で入手・配置してください。
- 一覧の先頭（名前順）のフォルダが既定モデルです。変更するなら `--default-model "フォルダ名"`、またはアプリの設定「詳細設定 → モデル名」。
