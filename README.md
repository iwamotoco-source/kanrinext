# 工事管理next

小田急線の工事管理用ワークスペース。カレンダー・小田急マップ・タスク・現場ツールを1画面にまとめています。

## 使い方

### デスクトップで使う
1. フォルダごとデスクトップなど好きな場所に置く
2. `index.html` を Edge / Chrome で開く
3. 地図の駅から駅フォルダを開くには、最初に一度だけ `インストール.cmd` を実行（`kouji://` を登録）

- 予定・タスクはそのブラウザ内に保存されます。設定 → バックアップ から `.json` に書き出せます。
- Leaflet・PDF.js・JSZip・jsPDF は同梱済みなので、地図の背景と天気以外はオフラインでも動きます。
- PDF整理ツールの `pdf-lib` だけはネット経由で読み込みます（オフラインで使う場合は `tools/lib/pdf-lib.min.js` を置く）。

### GitHub Pages / iPhone
1. このフォルダの中身をリポジトリに push（`main` ブランチ）
2. Settings → Pages → Source を **GitHub Actions** にする（`.github/workflows/pages.yml` が自動デプロイ）
3. iPhone は Safari の「ホーム画面に追加」でアプリとして使えます

### 端末間の同期
設定 → GitHub同期 に Owner / Repository / Token（Fine-grained, Contents: Read and write）を入力。
最終更新が新しい方のデータを採用します。Token は端末内にのみ保存されます。

## 画面
| 画面 | 内容 |
|---|---|
| ホーム | 今日と7日間の予定、天気（時間/週間）、現行案件、地図 |
| カレンダー | 日 / 稼働日 / 週 / 月 / 一覧 |
| 小田急マップ | 航空写真/地図切替、路線ごとの表示切替、駅検索（ひらがな可） |
| タスク | 右パネル。「経堂 盤の結線確認 明日 10:00」で駅・期日・時刻を自動認識 |
| ツール | PDF整理・Excel画像抽出・図面計測・数量拾い・電気計算・交通費記録（アプリ内で表示） |

`Ctrl + K` で駅・予定・ツール・操作をまとめて検索できます。

## カレンダー機能（Outlook相当）
- 時間軸表示、終日・複数日予定、重なった予定の横並び表示、現在時刻線
- ドラッグで作成・移動・時間変更、クリックで詳細、ダブルクリックで編集
- 繰り返し（毎日/平日/毎週・曜日指定/毎月・日付または第n曜日/毎年、間隔・終了日・回数）
- 繰り返しの「この回のみ / この回以降 / すべて」編集・削除
- 通知（アプリを開いている間）、公開方法（予定あり/空き時間/仮/外出中）、場所、メモ
- 日本の祝日、週番号、稼働日・稼働時間、週の開始曜日
- ミニカレンダー、種別ごとの表示切替、検索
- ICS 読み込み・書き出し（Outlook / iPhone と相互にやり取り）、印刷、元に戻す
- 独自機能：駅ラベル → 地図・駅フォルダ、期日付きタスクの表示

未対応：会議の招集（出欠管理）、Outlook/Exchange との自動同期、他の人との予定共有

## フォルダ構成
```
index.html            アプリ本体
assets/css, js        画面とロジック（file:// でも動く通常スクリプト）
assets/vendor/leaflet 地図ライブラリ
tools/                各ツール（tools/lib に同梱ライブラリ）
icons/ manifest.json service-worker.js   PWA
インストール.cmd / アンインストール.cmd     駅フォルダを開くための Windows 登録
```
