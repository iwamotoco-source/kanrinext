形式ごとの圧縮方法
画像
JPEG・WebPは再圧縮。PNGは透過と画素を保って再保存します。解像度は変えません。JPEG・WebPの再保存では位置情報などのメタデータを除去します。GIF・アニメーション・SVGは変更しません。
動画
MP4・MOV・M4VはH.264で再圧縮。音声は再圧縮せずコピーします。HDRは色が変わるのを避けるため変更しません。ほかの形式・対応できないコーデックは元ファイルを残します。初回のみ動画エンジン約31 MBを取得します。
PDF
文字・図形・ページを残して構造を再圧縮し、見た目優先では対応するJPEG画像だけ再圧縮します。ページ全体の画像化はしません。署名・パスワード付きPDFは変更しません。
Excel
XLSX・XLSMの内部を再圧縮し、見た目優先ではJPEG・PNG写真も処理します。数式・書式・マクロなどの他の内部ファイルはそのまま保持します。署名付き・旧形式XLSは変更しません。

「画質・内容を変えない」では画像・動画・未対応形式をZIPに包みます。小さくならない場合は元ファイルを採用。目標サイズは保証できず、超えた場合は結果に表示します。動画の処理中はこの画面を開いたままにしてください。
