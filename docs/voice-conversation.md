# 会話モード

AI Workspaceの入力欄横にある「会話」を押すと、会話モードが開きます。「話す」を押して話すと、確定した認識結果が自動送信されます。「話し終わり」でも発話を終了できます。回答は選択済みの読み上げ音声（Piper-plusなど）で再生します。再生後は次の「話す」操作を待ち、自動でマイクを再開しません。

「停止」は音声認識、生成・再生、応答待ちを中止します。終了・閉じる・履歴切り替え・バックグラウンドへの移動でも会話モードを終了します。過去の回答の読み上げ操作は会話モードを終了して行います。保存済みの自動読み上げ設定は変更しません。

音声認識に非対応のブラウザでは、キーボードの音声入力と送信ボタンを使用できます。Piper-plusの音声データはAI設定で取得しておいてください。音声認識はブラウザのサービスに依存します。文章は既存のAI設定と同じ経路で処理し、予定・タスクへの操作候補の確認も従来どおりです。新しい音声APIやAPIキーは追加していません。

## 検証

`node scripts/test-conversation.cjs`（Playwrightが必要、`TEST_CHROMIUM_PATH`でChromiumを指定可能）で、実画面・音声ルーター・AI HTTPクライアントを通した流れを検証します。音声認識と読み上げのイベント、AI応答はテスト用に再現し、外部の天気・地図・AI等への通信を遮断します。自動送信、回答の読み上げ、次の発話、停止後の遅延イベント、許可エラー、画面を閉じる、通常音声入力、キーボードによる代替、390px幅を確認しています。iPhone実機の音声認識とマイク許可は未検証です。
