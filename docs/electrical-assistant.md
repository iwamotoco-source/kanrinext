# 電気法令・検査アシスト

`tools/electrical-assistant.html` / メインアプリ `#tool/law`。

nktkt/deepelectricalwork の MIT 原案をスマホ用に再実装した。ライセンスは assets/vendor/deepelectricalwork/LICENSE.txt に同梱。

## 法令

電気事業法、電気工事士法、電気用品安全法、電気工事業法、電気設備技術基準省令の本則を検索。附則・別表・電技解釈・内線規程は検索対象外。条文番号、本文、公式リンク、取得時刻、施行日を表示。

e-Gov API v2 はXMLそのものではなく base64 XMLを law_full_text に含むJSONを返す。DOMParserを利用し、法令IDと CurrentEnforced を確認する。元コードの電気工事士法、電気工事業法、技術基準省令の法令IDを修正。

同梱スナップショットは scripts/update-electrical-laws.py で取得。UIの更新は選択法令だけ公式APIにアクセス。取得失敗では保存済み表示を維持。localStorageで新しい取得分を保存し、直前本文との追加・変更・削除を比較。これは全改正履歴の比較ではない。

## 検査記録

3種類の雛形。現場・検査日・記録者ごとの複数記録、未確認/確認済/要是正/対象外、測定値・判定基準・メモ。JSON入出力とCSV出力。

元テンプレートの固定数値（高圧1000MΩ、漏電遮断器一律0.1秒等）、条件を省略した接地抵抗、法定手続きや保存期間の断定を採用せず、仕様・設備区分に応じた基準を記録する構成へ変更。計算機は既存ツールを維持し、元コードの数値表は移植しない。

記録はこのブラウザのlocalStorage、平文。GitHub同期の対象外。JSON・CSVも平文。AI会話はメモリのみ。

## AI

メインアプリの同一オリジン iframe から既存 KoujiAI._i.postAi を利用。現在設定されているGemini等とアクセスキーを再利用。独立ページからはメインアプリへ誘導。予定・タスクは送信しない。

最大8条文、合計30000文字。検査添付は項目名を含む添付時点のスナップショット。送信チェックを必須とし、質問/選択条文/添付記録のみ送る。資料にない条文を生成しないよう依頼。公式リンクはAI回答から抽出せず、渡した資料から画面が生成する。モデルの引用内容・回答の正確さを保証する機能ではない。

会話は直近6メッセージを共有。参照条文/検査添付の変更で履歴を切り替える。90秒で中止。HTML挿入は使用せずtextContentで表示。
