# 配線ルート・電圧降下

PDF読み込み、縮尺又は2点校正、図面を開く、ルートを描く、の順に使用します。縮尺と校正係数はPDFの基準座標に対して保持するため、図面の表示倍率によって配線長は変わりません。

## 図面操作

- ホイール：ポインタ位置を中心に10～800%で拡大・縮小。
- 中ボタン又はSpace＋ドラッグ：図面移動。閲覧モードは通常のドラッグでも移動。
- スマホ：2本指で拡大縮小・移動。閲覧モードでは1本指で移動。描画モードの1本指タップで点を追加。
- 「全体」：表示領域へ収める。「100%」：基準表示へ戻す。「Esc」：描画終了。

描画の誤追加を防ぐため、移動・ピンチ直後のクリックは抑制します。PDFの再描画は短時間の操作終了後にまとめ、ビットマップは最大約800万画素に制限します。極端な拡大では画面の鮮明さに限界があります。

## ケーブルと計算

CV、CVT、CVQ、EM-CE、EM-CET、VV、VVF、VVR、EM-EEF、IV、HIV、EM-IE、KIV、VCT、VCTF、2PNCT、CVV、EM-CEE、その他を選択できます。収録サイズは選定の候補であり、全メーカー・全芯数の製品ラインナップを保証する一覧ではありません。採用品の型式・サイズ・温度条件を確認してください。

VVF・EM-EEFは単線径mmを指定し、A=πd²/4で断面積を換算します。他の候補は公称断面積mm²を指定します。VVFは[SFCC製品カタログ](https://www.swcc.co.jp/sfcc/products/pdf/SFCC_Catlog_S_web.pdf)、VVRは[SFCC製品資料](https://www.swcc.co.jp/sfcc/products/pdf/SF-0016_VVR.pdf)の20℃最大導体抵抗を使用します。それ以外は銅の抵抗率0.0178Ω·mm²/mによる概算で、製品固有の交流抵抗やインピーダンスではありません。「20℃導体抵抗を指定する」で採用品の値（Ω/km）を入力できます。この場合はサイズごとの抵抗が分からないため、自動サイズ選定を止めます。

片道施工長L=(図面長＋立上り下り＋固定余長)×(1＋施工余裕/100)。Rₜ=R₂₀×[1＋0.00393×(T−20)]。抵抗成分だけの電圧降下はΔV=k×I×(L/1000)×Rₜで、kは単相2線・直流2線が2、平衡三相3線が√3です。画面に各式・代入値・計算結果を表示します。交流は力率1を仮定し、リアクタンス等は含みません。一般の交流計算の根拠は[FDC技術資料](https://www.fujikura-dia.co.jp/tech/documents/voltage-drop.php)を参照してください。

自動候補は電圧降下だけの照合結果です。許容電流、工法、保護協調、短絡、高調波等の検討を別途行います。旧バージョンの回路データは従来の保存キーで維持します。

## 検証

`node scripts/test-cable-route.cjs` を使用。HTTPサーバーを別途起動し、`TEST_CHROMIUM_PATH`でChromiumを指定できます。抵抗計算、単線径、式、拡大前後の長さ不変、ポインタ中心拡大、パン時の誤描画防止、ピンチイベント、390px画面を確認します。実機iPhone Safariの確認は含みません。

## 器具の消費電流と台数

器具名・1台の入力電流A・台数を行ごとに入力し、全台同時使用の合計電流Σ(I×台数)を自動計算します。新規回路は電流を空欄にし、入力するまで判定しません。異なる種類は行を追加します。既存回路の合計電流は「既存の合計電流（内訳を編集）」1台として移行し、既存結果を保持します。回路ごとに内訳を保存します。台数は0以上の整数で、消費電流は0以上です。

この入力は器具内訳の合算に対応するものです。接続位置による区間ごとの電流減少は未計算で、全負荷が末端にあるモデルを使用します。
