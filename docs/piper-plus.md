# Piper-plus の端末内読み上げ

AI設定で「Piper-plus・つくよみちゃん」を選び、「音声データを取得」→「試し聞き」→「保存」。AIの回答の読み上げボタンと、自動読み上げに使用されます。初回取得だけネット接続が必要です。音声生成のために本文やAPIキーを外部へ送ることはありません。

音声モデルは約40 MB、日本語辞書入りWASMは約60 MB、ONNX Runtime WASMは約12 MB。保存容量は合計約115 MBです。通信量は配信側の圧縮により変わります。モデルをアプリの初回インストール時に自動取得することはありません。取得済みデータは専用Cache Storageに保存し、アプリ更新では消しません。「音声データを削除」で削除できます。ブラウザが保存データを削除した場合は再取得してください。

音声生成は専用のmodule Worker一つで順番に実行し、本文を最大80字程度に区切って再生します。停止は再生中の音源と生成中のWorkerを停止します。再開時は取得済みデータを再利用します。SharedArrayBuffer不要の単一スレッドWASMを使用します。WebGPUや音声サーバーは不要です。端末によって生成時間とメモリ消費は異なります。

## 固定した依存関係

- Piper-plus 0.7.0 / @piper-plus/g2p 0.4.2（MIT）
- ONNX Runtime Web 1.24.3（MIT）
- 音声モデル：ayousanz/piper-plus-tsukuyomi-chan、revision `36b59c825c36bd386b8960cf3f604382f52f2a87`、FP16 MB-iSTFT-VITS2
- モデルと設定はHugging Face、日本語辞書WASMはunpkg、実行エンジンWASMはjsDelivrから取得します。大きなバイナリはこのリポジトリに同梱しません。

npm 0.7.0の既定話者入力（192次元・1次元マスク）を、固定モデルが要求する256次元・2次元マスクに合わせる互換処理をWorkerに入れています。

`bash scripts/build-piper.sh` でローカル配信するJSを再生成できます。通常のGitHub Pages配信にnpmやビルドは不要です。ライセンスは `assets/vendor/piper-plus/` に収録しています。

## 音声のクレジット・利用条件

本ソフトウェアの音声合成には、フリー素材キャラクター「つくよみちゃん」（© Rei Yumesaki）が無料公開している音声データを使用しています。

つくよみちゃんコーパス（CV.夢前黎）：https://tyc.rei-yumesaki.net/material/corpus/

Piper-plusの音声を次の目的で使用することを禁止します。

- 人を批判・攻撃すること（定義は https://tyc.rei-yumesaki.net/about/terms/#condition3 に準じます）。
- 特定の政治的立場・宗教・思想への賛同または反対を呼びかけること。
- 刺激の強い表現をゾーニングなしで公開すること。
- 他者に対して二次利用（素材としての利用）を許可する形で公開すること。

つくよみちゃんコーパスに由来する部分を改変・再配布する場合も、同コーパスの利用規約に従ってください。これらの条件は派生ソフトや再配布されたデータにも引き継がれます。全文は上記配布ページの利用規約を参照してください。音声モデルの作者はayousanz、Piper-plusの作者はayutazです。
